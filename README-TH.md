## โครงไฟล์

```

config.js      ไฟล์ตั้งค่า  กุญแจอยู่ที่นี่ไฟล์เดียว
docs/          เอกสาร 8 ไฟล์
```

## สิ่งที่การแยกไฟล์ให้และไม่ให้

| หัวข้อ | ผล |
|---|---|
| แก้กุญแจง่ายขึ้น | **ได้** แก้ไฟล์เดียวบรรทัดเดียว |
| ส่งโค้ดให้คนอื่นโดยไม่ติดกุญแจ | **ได้** ส่งแค่ index.html กับ docs |
| เปลี่ยนกุญแจโดยไม่กระทบโค้ด | **ได้** |
| ซ่อนกุญแจจากคนทั่วไป | **ไม่ได้** |

### ทำไมถึงซ่อนไม่ได้

GitHub Pages เผยแพร่ทุกไฟล์ใน repo ต่อสาธารณะเหมือนกันหมด

ใครก็เปิดที่อยู่นี้ได้ตรง ๆ

```
https://ชื่อผู้ใช้.github.io/ชื่อrepo/config.js
```

แล้วเห็นกุญแจทันที โดยไม่ต้องกด F12 ด้วยซ้ำ

**การแยกไฟล์ช่วยเรื่องการจัดการ ไม่ได้ช่วยเรื่องความปลอดภัย**

## ถ้าจะใช้ ต้องทำสี่อย่างนี้

1. **สร้างกุญแจใหม่เฉพาะงานนี้** อย่าใช้ตัวเดียวกับงานอื่น
2. **จำกัดวงเงิน** ใน Google Cloud Console หรือใช้โปรเจกต์ที่ไม่ผูกบัตร
3. **จำกัดโดเมนที่เรียกได้** ตั้ง HTTP referrer เป็น `https://ชื่อผู้ใช้.github.io/*`
4. **ลบกุญแจทิ้งทันทีที่เลิกใช้**

ข้อ 3 สำคัญที่สุด เพราะถึงกุญแจหลุด คนอื่นก็เอาไปใช้จากเว็บตัวเองไม่ได้

## วิธีติดตั้ง

### ขั้นที่ 1 สร้าง repo

GitHub → New repository → เลือก **Public** → ติ๊ก Add a README file

### ขั้นที่ 2 อัปไฟล์

อัป `index.html` และ `config.js` ไว้ชั้นนอกสุด

แล้วอัปเอกสารด้วย Add file → Create new file
พิมพ์ชื่อเป็น `docs/01-leave.txt` ทำให้ครบแปดไฟล์

### ขั้นที่ 3 ใส่กุญแจ

เปิด `config.js` บน GitHub แล้วกดรูปดินสอ แก้บรรทัดนี้

```javascript
KEY: "AQ.Ab8RN6xxxxxxxxxxxxxxxx",
```

กด Commit changes

### ขั้นที่ 4 เปิด GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save

### ขั้นที่ 5 ทดสอบ

เปิดลิงก์ ระบบเตรียมตัวเองอัตโนมัติ แล้วขึ้นว่า

```
พร้อมใช้งาน   เอกสาร 8 ไฟล์  16 ชิ้น   รุ่น gemini-3.8-flash
```

ถ้าขึ้นข้อความอื่น ให้ดูตารางด้านล่าง

## ตารางแก้ปัญหา

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| ไม่พบไฟล์ config.js | ยังไม่ได้อัป หรืออัปผิดโฟลเดอร์ | ต้องอยู่ชั้นเดียวกับ index.html |
| ยังไม่ได้ใส่กุญแจ | ยังเป็นข้อความตัวอย่าง | แก้บรรทัด KEY ใน config.js |
| ไม่มีรายชื่อไฟล์เอกสาร | รายการ FILES ว่าง | ตรวจ config.js |
| อ่านไฟล์ docs ไม่ได้ | ยังไม่ได้สร้างโฟลเดอร์ docs | ใช้ Create new file แล้วพิมพ์ `docs/` นำหน้า |
| ขึ้น 400 หรือ 403 | กุญแจผิด หรือถูกจำกัดโดเมน | ตรวจกุญแจ และตรวจ HTTP referrer |
| ขึ้น 429 | เรียกถี่เกินโควตาฟรี | รอสักครู่ ระบบลองใหม่ให้เอง |
